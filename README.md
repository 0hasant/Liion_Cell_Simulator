# Cell Test Bench

Single-cell characterization bench for 18650 and 21700 Li-ion cells (DMEGC INR45E, generic 3.5 Ah 18650). The goal is a fitted **2RC equivalent-circuit model** (OCV, R0, R1/C1, R2/C2 versus SOC and temperature). Part of the Solaris final-year project.

- 0–10 A linear electronic load (constant current), down to 2.0 V
- Charging up to 5 A from a 30 V bench PSU through an XL4016 module, with voltage **and** current limit set by the MCU
- Bidirectional current on one 10 mΩ shunt with Kelvin taps; Kelvin cell voltage on a 16-bit ADS1115
- Cell held at about 10–45 °C in an insulated pocket, cooled or heated by two TEC1-12706 Peltiers
- STM32F103 Blue Pill, USB CDC to a Python UI
- Hardware protection (OV, UV, OC, OT) that latches and cuts relay and Peltier power without the firmware

## Board overview

- **Left edge:** PSU input (J101), 12 V buck module (J102), charger module (J401), FB tap (J402).
- **Top edge:** thermostat (J104), fans (J704–J706), Peltier output (J702), Blue Pill with USB at the edge.
- **Right edge:** four NTC terminals (J501–J504).
- **Bottom edge:** cell power (J205), 0.1 Ω load resistor (J301), IRFP260N (Q301, tab facing out onto the load cooler), Kelvin sense (J206).
- `PGND` (power return) and `GND` (signal) are separate nets, joined at one wire link (JP201) next to the shunt.

## Blue Pill pin map

| Pin | Signal | Function |
|---|---|---|
| PA0 / PA1 | I_MON / V_FAST | ADC: fast current (1.71 V + 0.12 V/A), fast cell voltage ÷ 2 |
| PA2–PA5 | NTC_CELL, NTC_AIR, NTC_HS, NTC_TEC | ADC: temperatures |
| PA6 / PA7 / PB0 | PWM_L / PWM_C / PWM_I | TIM3: load setpoint, charger voltage, charger current limit |
| PA8 | FAN_PWM | TIM1_CH1: both cooler fans |
| PA9 / PA10 | DBG_TX / DBG_RX | Debug UART (J803) |
| PB6 / PB7 | SCL / SDA | I2C1: ADS1115 at 0x48 |
| PB8 / PB9 | TEC_PWM / TEC_DIR | Peltier power (TIM4) and heat/cool relay |
| PB10 | ARM | High-Z normally; high pulse = re-arm protection, low = force trip |
| PB12 / PB13 | K1_EN / K2_EN | Charger relay / load relay |
| PB14 | LOAD_OFF | Open drain; low = load enabled |
| PB15 | FAULT_N | Low = protection tripped |

## Key design numbers

- Load: `I ≈ (PWM × 0.119 V − 5 mV) / 10 mΩ`, full scale about 11.3 A; firmware closes the loop on the ADS1115.
- Charger: CV trimmer set to **4.25 V** (hardware ceiling); hardware current limit 0–5.6 A.
- Trips: OV > 4.33 V, UV < 1.96 V, discharge > 11.6 A, charge > 6.2 A, heatsink or cell > about 61 °C. Latched; power-up state is tripped.

## Regenerating

```
cd hardware/tools
python3 design.py ../kicad                         # schematic (overwrites the KiCad sheets)
python3 makelib.py ../kicad                        # project footprint library + 3D models
kicad-cli sch export netlist --format kicadsexpr -o /tmp/net.net ../kicad/cell_test_bench.kicad_sch
python3 verify.py /tmp/net.net                     # netlist vs design
python3 pcbgen.py /tmp/net.net ../kicad 1          # outline + placement (overwrites the PCB)
python3 route2.py ../kicad/cell_test_bench.kicad_pcb /tmp/routed.kicad_pcb 32   # single-sided router, ~30 min
python3 cleanup.py /tmp/routed.kicad_pcb ../kicad/cell_test_bench.kicad_pcb
python3 fab.py ../kicad/cell_test_bench.kicad_pcb ../fab
python3 bom.py ../bom.csv ../bom_offboard.csv
```

Once you edit the board or schematic in KiCad by hand, those files are the source of truth: don't re-run the generators after that.
